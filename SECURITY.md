# Security

This project is an experimental single-admin MVP, not a production hypervisor control plane. Keep access on localhost/private networks. Never publish actual PVE tokens, API keys or unredacted logs. Use a dedicated low-privilege API token scoped to specific VM IDs and enforce PVE TLS certificate validation. Submit sensitive security issues privately to the maintainers rather than filing a public issue. Any virtual machine action requires an explicit one-time approval.
